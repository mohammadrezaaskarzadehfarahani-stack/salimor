# نسخه‌ی نمایشی سالیمور در WordPress Playground

این پوشه فقط برای نمایش است و جزو قالب نیست.

**لینک نمایش:**
https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/mohammadrezaaskarzadehfarahani-stack/salimor/playground/playground/blueprint.json

- اولین بار باز شدن ۱ تا ۳ دقیقه طول می‌کشد. وردپرس، ووکامرس و ووکامرس فارسی نصب می‌شوند و محصولات نمونه ساخته می‌شوند.
- هر بازدیدکننده یک نسخه‌ی جدا و موقت دارد که با بستن صفحه پاک می‌شود.
- **ورود با موبایل** در حالت آزمایشی است: هر شماره‌ای وارد کنید، کد روی همان صفحه نمایش داده می‌شود.
- **پرداخت** واقعی نیست.
- **پیشخوان وردپرس**: `/wp-admin` با نام کاربری `admin` و رمز `password`.
- قالب مستقیم از شاخه‌ی `main` نصب می‌شود. هر تغییری که در `main` بدهید، دفعه‌ی بعد در نمایش دیده می‌شود.

| فایل | کار |
|---|---|
| `blueprint.json` | مراحل ساخت سایت نمایشی |
| `seed.php` | محصولات، دسته‌ها، نوشته‌ها، روش‌های ارسال و برگه‌های نمونه |
| `demo-mu-plugin.php` | دو تنظیم مخصوص Playground (نوار «نسخه‌ی نمایشی» و خاموش کردن رزرو موجودی، که پایگاه داده‌ی مرورگر پشتیبانی نمی‌کند). روی هاست واقعی لازم نیست. |
| `sample/` | عکس‌های نمونه‌ی محصولات |
