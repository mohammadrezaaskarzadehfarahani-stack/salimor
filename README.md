# قالب سالیمور — راهنمای نصب (نسخه ۰٫۲ — فاز ۲)

قالب اختصاصی وردپرس + ووکامرس برای فروشگاه سالیمور. فارسی، راست‌چین، با حالت اپلیکیشنی در موبایل و قابل نصب روی گوشی (PWA).

## پیش‌نیازها
- وردپرس ۶٫۵ یا بالاتر، PHP ۸٫۱ یا بالاتر
- افزونه‌ی **WooCommerce**
- افزونه‌ی **ووکامرس فارسی** (Persian WooCommerce) برای تاریخ شمسی، استان‌ها و درگاه‌ها
- هاست با **HTTPS** (برای نصب شدن سایت روی گوشی ضروری است)

## نصب
1. پیشخوان ← نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته ← فایل `salimor.zip` ← فعال‌سازی.
2. تنظیمات ← عمومی: زبان «فارسی»؛ ووکامرس ← تنظیمات: واحد پول «تومان».
3. تنظیمات ← خواندن: «یک برگه‌ی یکتا»
   - برگه‌ی نخست: یک برگه‌ی خالی به نام «خانه» (طرح صفحه‌ی اصلی خودکار ساخته می‌شود)
   - برگه‌ی نوشته‌ها: برگه‌ای به نام «ژورنال»
4. تنظیمات ← پیوندهای یکتا: «نام نوشته».
5. نام برگه‌ی فروشگاه ووکامرس را «فروشگاه» بگذارید.

## منوها (نمایش ← فهرست‌ها)
- **منوی اصلی**: منوی بالای سایت در دسکتاپ. اگر خالی بماند خودکار «خانه، فروشگاه، سه دسته‌ی اصلی، ژورنال» نمایش داده می‌شود.
- **فوتر ۱، ۲، ۳**: سه ستون فوتر (مثلاً فروشگاه / راهنمای خرید / سالیمور).

## تنظیمات سالیمور (نمایش ← سفارشی‌سازی ← تنظیمات سالیمور)
- **بخش بالای صفحه**: تیتر، متن و دکمه‌های هیرو.
- **تماس و شبکه‌ها**: تلفن، ایمیل، ساعت کاری، نام کاربری تلگرام، اینستاگرام و بله. منوی پشتیبانی از همین‌ها ساخته می‌شود.
- **مزیت‌ها**: چهار مزیت زیر قفسه‌ها.
- **فروشگاه**: حداقل خرید برای ارسال رایگان (پیش‌فرض ۲٬۰۰۰٬۰۰۰ تومان).
- **کدها**:
  - کد چت آنلاین (گفتینو، رایچت، کریسپ یا توتو). بعد از گذاشتن کد، گزینه‌ی «چت آنلاین» خودکار به منوی پشتیبانی اضافه می‌شود.
  - کد نماد اعتماد (اینماد) و ساماندهی برای فوتر.
- **لوگو**: سفارشی‌سازی ← هویت سایت. اگر خالی بماند، لوگوی بته‌جقه‌ی سالیمور نمایش داده می‌شود.

## محصولات
- **دسته‌ها**: سه دسته‌ی اصلی (مثل زیورآلات، اکسسوری مد، دیجیتال) و زیردسته‌ها.
  - «توضیح» هر دسته زیر نام آن در صفحه‌ی اصلی نمایش داده می‌شود.
  - ترتیب دسته‌ها را با کشیدن و رها کردن در لیست دسته‌ها تعیین کنید.
  - برای هر دسته یک «تصویر بندانگشتی» بگذارید.
- **ویژگی رنگ**: محصولات ← ویژگی‌ها ← ویژگی‌ای با نامک `color` بسازید. برای هر رنگ در صفحه‌ی ویرایشش «رنگ نمایشی» (کد هگز) را وارد کنید تا دایره‌ی رنگی زیر کارت محصول نمایش داده شود.
- **تصاویر**: بهترین نتیجه با عکس پس‌زمینه‌ی شفاف (PNG یا WebP) یا پس‌زمینه‌ی روشن، با نسبت ۴ به ۵ (مثلاً ۱۲۰۰×۱۵۰۰).
- **قفسه‌های صفحه‌ی اصلی** خودکار پر می‌شوند:
  - تازه‌ها: جدیدترین محصولات؛
  - پرفروش‌ها: بر اساس فروش؛
  - تخفیف‌دارها: محصولات حراج.
  - اگر حراج «تاریخ پایان» داشته باشد، شمارش معکوس نمایش داده می‌شود.

## فروشگاه و فیلترها
- فیلترها خودکار ساخته می‌شوند و تنظیم جداگانه ندارند:
  - **محدوده‌ی قیمت**؛
  - **همه‌ی ویژگی‌های محصول** (رنگ، جنس، سایز و هر ویژگی که در «محصولات ← ویژگی‌ها» بسازید)؛
  - تخفیف‌دار، جدید (۳۰ روز اخیر) و فقط موجودها.
- هر گزینه تعداد محصولاتش را نشان می‌دهد. گزینه‌ای که با فیلترهای فعلی نتیجه‌ای ندارد کم‌رنگ می‌شود.
- لینک صفحه با فیلترها قابل اشتراک است (مثلاً `?color=طلایی&sale=1`).
- نوار دسته‌های اصلی در موبایل بالای صفحه ثابت می‌ماند. زیر آن، زیردسته‌ها نمایش داده می‌شوند.

## صفحه‌ی محصول
- **گالری**: تصویر شاخص به‌علاوه‌ی «گالری تصاویر محصول». فلش، نقطه‌ها، کلیدهای جهت و سوایپ در موبایل کار می‌کنند.
- **محصول متغیر** (مثلاً رنگ و سایز):
  - برای هر ویژگی که «برای متغیرها استفاده شود»، دکمه‌های انتخاب نمایش داده می‌شوند. رنگ‌ها دایره‌ای‌اند.
  - قیمت و تصویر با انتخاب کاربر عوض می‌شود.
  - ترکیب‌های ناموجود خط‌خورده نمایش داده می‌شوند.
- **بعد از افزودن به سبد**، دکمه به کنترل تعداد و «مشاهده سبد» تبدیل می‌شود. در موبایل این نوار پایین صفحه ثابت است.
- **بخش‌ها**:
  - «توضیحات» از متن اصلی محصول می‌آید؛
  - «مشخصات» از ویژگی‌های قابل نمایش، وزن، ابعاد و شناسه (SKU) ساخته می‌شود؛
  - «ارسال و بازگشت» از سفارشی‌سازی ← تنظیمات سالیمور ← فروشگاه می‌آید.
- **لینک راهنمای سایز**: اگر در همان بخش وارد کنید، کنار ویژگی «سایز» نمایش داده می‌شود.
- **دیدگاه و امتیاز** محصول عمداً نمایش داده نمی‌شود.

## نصب روی گوشی (PWA)
بعد از فعال‌سازی، کاری لازم نیست. روی HTTPS:
- در **اندروید** بعد از دو بازدید پیشنهاد «نصب» نمایش داده می‌شود؛
- در **آیفون** راهنمای «Share ← Add to Home Screen» نمایش داده می‌شود.

سبد خرید، تسویه و حساب کاربری هیچ‌وقت کش نمی‌شوند. اگر کاربر آفلاین شود، صفحه‌ی «اتصال برقرار نیست» نمایش داده می‌شود.

## توصیه‌های هاست برای سرعت
- فشرده‌سازی **gzip یا brotli** روشن باشد.
- یک افزونه‌ی تبدیل تصویر به **WebP** نصب کنید (مثل Converter for Media).
- یک افزونه‌ی کش صفحه (مثل LiteSpeed Cache) نصب کنید. صفحات سبد، تسویه و حساب کاربری را از کش خارج کنید.
- افزونه‌ی سئو (Yoast یا Rank Math) اختیاری است. اگر نصب شود، توضیحات متا را خودش مدیریت می‌کند.

## آنچه تا الان آماده است
- **فاز ۱**:
  - ساختار قالب و صفحه‌ی اصلی؛
  - سبد کشویی بدون رفرش، علاقه‌مندی‌ها، نوار تب موبایل؛
  - ژورنال؛
  - PWA.
- **فاز ۲**:
  - فروشگاه و دسته‌ها با فیلترهای کامل؛
  - جستجوی محصول؛
  - صفحه‌ی محصول با گالری، محصولات متغیر و نوار خرید.

## فازهای بعد
- سبد و تسویه؛
- حساب کاربری با ورود پیامکی؛
- برگه‌های درباره، تماس، سؤالات متداول، ارسال و مرجوعی، قوانین.
